november-opencode is a theme for opencode: warm amber accents on blue-grey panels, with Night Owl-style syntax colours. It is the terminal counterpart of [november-vscode](/projects/november-vscode/docs), so the editor and the terminal look like the same place.

The whole theme is one JSON file, `november.json`. There is nothing to build and no dependency to keep up to date.

- [🎨 Palette and tokens](/projects/november-opencode/docs/palette) — every colour in the theme, and which role it plays
