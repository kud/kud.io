---
title: 🎨 Palette and tokens
description: The colours defined in november.json and how they map onto opencode's theme roles.
---

`november.json` has two sections. `defs` names the colours; `theme` assigns those names to opencode's roles. Hex values below are taken directly from the file.

## Core palette

| Role                    | Colour                |
| ----------------------- | --------------------- |
| Primary / active border | `#ff8700` orange      |
| Secondary / accent      | `#ff9e00` amber       |
| Panel / element         | `#20212e` / `#242533` |
| Text / muted            | `#e4e4ec` / `#949494` |
| Success / error         | `#56db3a` / `#dc322f` |
| Diff added / removed    | `#82aaff` / `#ff5364` |

## Diffs

Added and removed lines get a tinted background, and their line-number gutters get a stronger matching one, so the eye does not have to hunt for where a change starts.

| Token                     | Value                |
| ------------------------- | -------------------- |
| `diffAdded`               | `#82aaff`            |
| `diffRemoved`             | `#ff5364`            |
| `diffHighlightAdded`      | `#9bbdff`            |
| `diffHighlightRemoved`    | `#ff6f7c`            |
| `diffAddedBg`             | `#24395a`            |
| `diffRemovedBg`           | `#5a2a2a`            |
| `diffAddedLineNumberBg`   | `#33568a`            |
| `diffRemovedLineNumberBg` | `#763232`            |

## Changing a colour

Edit the value under `defs`, not under `theme`: the `theme` entries only reference names, so one edit recolours every role that uses it. See [Installation](/projects/november-opencode/docs/installation) for where the file lives.
