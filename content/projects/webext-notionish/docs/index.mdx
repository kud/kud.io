---
title: 👋 Introduction
description: A Firefox extension that restyles Google Docs and Sheets to read like Notion, hiding the chrome around the document.
---

**webext-notionish** (Notionish in Firefox) strips the toolbars, rulers and side rail from Google Docs and Sheets so the page is nearly the only thing on screen, then gives what survives a quieter, Notion-like finish. It changes how the document looks in your browser and nothing else: no one else's view of the document changes.

It is a prototype, Firefox only, and not yet on addons.mozilla.org, so for now it is loaded from source.
