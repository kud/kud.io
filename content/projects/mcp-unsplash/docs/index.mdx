mcp-unsplash is a read-only MCP server over the public Unsplash API. It exposes 20 tools for searching and browsing photos, collections, topics and photographers, and trims every response to the fields a model actually needs.

## What's here

- [🔑 Setup](/projects/mcp-unsplash/docs/setup) — get an Access Key, register the server with a client, and understand rate limits
- [🖼 Photos](/projects/mcp-unsplash/docs/photos) — search, list, random picks, full metadata, statistics, and attribution rules
- [📁 Collections and topics](/projects/mcp-unsplash/docs/collections-and-topics) — browse curated sets and editorial topics
- [👤 Users and stats](/projects/mcp-unsplash/docs/users-and-stats) — photographer profiles, their work, and platform-wide numbers
