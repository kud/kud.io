duux-cli is a terminal client for the Duux Whisper Flex 2 smart fan. Run `duux` with no arguments for a full-screen Ink control panel, or reach for one of its subcommands to sign in, discover fans, or script a change from a shell.

## What's here

- [🚀 Getting started](/projects/duux-cli/docs/getting-started) — sign in, discover a fan, and what happens on first run
- [🎛️ The TUI](/projects/duux-cli/docs/tui) — every row, every keybinding, and what `(unconfirmed)` means
- [⌨️ Commands](/projects/duux-cli/docs/commands) — full reference for every subcommand, from `auth` and `discover` to `preset`, `watch`, and `broker`
- [🔧 Troubleshooting & API notes](/projects/duux-cli/docs/troubleshooting) — which fan parameters are confirmed versus provisional, and how to probe the rest
