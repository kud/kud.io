jira-cli reads Jira as plain, pipeable text, including the attachments most tools leave behind. Every read takes `--json`, exit codes are stable, and the interactive board only appears when you run bare `jira` in a terminal.

## What's here

- [⚙️ Setup](/projects/jira-cli/docs/setup) — token, config file, custom fields and exit codes
- [🎫 Issues](/projects/jira-cli/docs/issues) — list, view, create, edit, transition, comment, link, rank and log work
- [📎 Attachments](/projects/jira-cli/docs/attachments) — list, read, download and upload files on an issue
- [🗂️ Boards and sprints](/projects/jira-cli/docs/boards) — projects, boards, sprints, epics and the backlog
- [🔎 Search and metadata](/projects/jira-cli/docs/search) — JQL, people, instance metadata and the raw API escape hatch
- [🤖 Automation rules](/projects/jira-cli/docs/automation) — list, export, import and switch Jira Automation rules
- [🖥️ Interactive view](/projects/jira-cli/docs/interactive) — the terminal board behind bare `jira`
