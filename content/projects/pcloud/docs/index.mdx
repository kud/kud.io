`@kud/pcloud` is the pCloud core: one typed client, one set of authentication helpers and a few presentation utilities, so every front end built on pCloud behaves the same way. It runs on Node.js 20 or later.

## What's here

- [🔐 Authentication](/projects/pcloud/docs/authentication) — session tokens, OAuth, two-factor and how stored credentials are resolved
- [📁 Client](/projects/pcloud/docs/client) — the `PCloudAPI` class: files, folders, sharing, public links, trash and revisions
- [⏪ Rewind](/projects/pcloud/docs/rewind) — recovering from an accident by replaying the change log
- [🧰 Helpers](/projects/pcloud/docs/helpers) — formatting, path resolution and the offline mock account
