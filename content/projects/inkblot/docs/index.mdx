Inkblot is a tiny page-transition library: one function, one empty element, and a circle of colour that spreads from wherever you clicked, its rim wobbled like wet ink. It is pure CSS and SVG, with no runtime dependencies and no framework lock-in.

## What's here

- [🖋️ Usage](/projects/inkblot/docs/usage) — the `spill()` and `clear()` functions, the three modes and every option
- [🎨 Styling](/projects/inkblot/docs/styling) — the overlay element, custom properties, reduced motion and strict CSP setups
- [🧩 Environments](/projects/inkblot/docs/environments) — vanilla, React, Next.js and CDN recipes
