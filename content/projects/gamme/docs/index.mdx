Gamme fixes what colour roles mean, and the shape, spacing, motion, type and accessibility-carrying components, so every kud Android app looks and behaves like part of one family. Colour values stay with each app.

The code has not landed yet: it arrives after pastille's first F-Droid release. These pages describe the v0.1 specification the kit will be built to.

## What's here

- [🎨 Tokens](/projects/gamme/docs/tokens) — colour roles, shape, spacing, type, motion, haptics and glyphs
- [🧩 Components](/projects/gamme/docs/components) — the theme and the six components v0.1 ships
- [📐 Rules](/projects/gamme/docs/rules) — the rulings every app carries, drawn from reviewing on a real phone
- [🚚 Adoption](/projects/gamme/docs/adoption) — how an app takes the kit, and what visibly changes
