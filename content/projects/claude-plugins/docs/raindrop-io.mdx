---
title: 🔖 raindrop-io
description: Manage your Raindrop.io bookmarks from Claude — search your library, save new links, organise into collections, and tag.
---

The **raindrop-io** plugin connects Claude to
[Raindrop.io](https://raindrop.io)'s official MCP server, and adds three skills on
top of it. Search your library by meaning, save links without creating duplicates,
and reorganise in bulk with a confirmation step before anything is written.

## 🧰 What it bundles

| Skill                | Trigger                          | What it does                                                          |
| -------------------- | -------------------------------- | --------------------------------------------------------------------- |
| `/bookmark-search`   | `/bookmark-search <query>`       | Semantic search across titles, notes, URLs, tags and page text         |
| `/bookmark-save`     | `/bookmark-save <url>`           | Saves a URL, checking first whether it is already in your library      |
| `/bookmark-organise` | `/bookmark-organise <what to do>` | Bulk moves, tagging and cleanup — always previewed before it is applied |

## 📦 Install

```
/plugin install raindrop-io@kud --scope user
```

## 🔧 Configuration

None. The server uses OAuth 2.1 — Claude opens a browser on first use so you can
authorise it against your Raindrop account. There is no API token to create, store,
or keep alive across machines.
