title: 👋 Introduction
description: A real-time planning poker table for estimating user stories together, with no accounts and no database.
---

**planning-poker** is a shared card table for estimation sessions: everyone joins a room by link or code, votes face-down, and the host flips the cards at once so nobody anchors on anyone else. A small room server on Cloudflare Workers keeps the table in sync, and a Next.js app draws the felt.

## 🧭 What's here

- [🃏 Playing a round](/projects/planning-poker/docs/usage) — joining a room, voting, hotkeys, the speaker ritual, breaks and reactions
- [🎩 Host controls](/projects/planning-poker/docs/host-controls) — decks, reveal and auto-reveal, timers, topics and history, join approval, Rage Mode
- [🛠️ Self-hosting](/projects/planning-poker/docs/self-hosting) — how rooms work, the scripts, the room server address and the test crew
