**harness-fme** is a terminal client for Harness FME (Split) feature flags. It shows where each flag stands in every environment, and it changes targeting from the shell with a plan first, a backup before every write and a read-back after it.

Target: **Node >= 20**, binary `harness-fme`.

## What's here

- [📖 Usage](/projects/harness-fme-cli/docs/usage): the reading commands, the writing commands, `--json` and exit codes
- [🛡️ Safe writes](/projects/harness-fme-cli/docs/safe-writes): plans, backups, read-back, pacing and the production guard
- [🖥️ Interactive dashboard](/projects/harness-fme-cli/docs/interactive): `harness-fme tui`, its keys and its confirmation step
- [⚙️ Configuration](/projects/harness-fme-cli/docs/configuration): environment variables and the optional `fme` alias
