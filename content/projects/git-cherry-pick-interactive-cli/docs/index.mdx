title: 👋 Introduction
description: Pick commits from another branch in a terminal checklist and cherry-pick them in one go.
---

git-cherry-pick-interactive-cli adds a `git cherry-pick-interactive` command. Give it a branch, tick the commits you want from a checklist, and it applies them to your current branch in order. No more copying hashes out of `git log`.

## What's here

- [⌨️ Usage](/projects/git-cherry-pick-interactive-cli/docs/usage) — running the command, the checklist keys and what the output means
- [🔍 How it works](/projects/git-cherry-pick-interactive-cli/docs/how-it-works) — which commits are listed, in what order, and what happens on conflicts or errors
