**segment** is a small family of packages for the Segment Public API. A
zero-dependency core client does the talking, and the `segment` command sits on
top of it so you can inspect sources, wire up destinations and read the
destination catalog without opening the dashboard.

Three packages live in the monorepo, and the flow only goes one way:

| Package            | Role                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| `@kud/segment`     | The core: `SegmentClient`, config resolution and types. No terminal.  |
| `@kud/segment-ink` | Ink components for sources, destinations and the catalog.            |
| `@kud/segment-cli` | The `segment` binary, a thin layer over the other two.                |
