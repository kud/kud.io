---
title: 👋 Introduction
description: Publish Now Playing metadata to macOS Control Center and receive its media-button events, from Node.
---

macos-nowplaying-bridge lets a Node process show up in macOS Control Center as the thing that is playing, and hear back when someone presses play, pause, next or previous. It does the native work with a small Swift co-process, so your code stays plain TypeScript.
