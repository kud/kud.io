---
title: 👋 Introduction
description: A command-line wrapper for sending macOS system media keys to whichever player is active.
---

`media-keys` sends the same system media key events as your keyboard's play, skip and seek keys, so any script, shortcut or terminal session can control Music, Qobuz, Spotify or whatever else is currently listening. It is a thin layer over the [`@kud/macos-media-keys`](/projects/macos-media-keys/docs) library.

## What's here

- [🎛️ Commands](/projects/macos-media-keys-cli/docs/commands) — the five subcommands, what each key does and how invalid input is handled
- [🔐 Permissions and scripting](/projects/macos-media-keys-cli/docs/permissions) — the Accessibility requirement, exit codes and using `media-keys` from scripts
