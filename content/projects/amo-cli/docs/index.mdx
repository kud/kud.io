---

amo-cli is the `amo` command. It treats your add-on's AMO listing as files in a repository: you edit them locally, run a dry run to see exactly what differs from the live page, then send only the differences.

## What's here

- [⚙️ Configuration](/projects/amo-cli/docs/configuration): API credentials, environment fallbacks and the dry-run default.
- [🚦 Status](/projects/amo-cli/docs/status): check the listing and latest version review state.
- [📝 Listing](/projects/amo-cli/docs/listing): pull the live listing to a file, push edits back, and limit a push with `--only`.
- [🖼️ Screenshots](/projects/amo-cli/docs/screenshots): make AMO's previews match a directory of images and captions.
