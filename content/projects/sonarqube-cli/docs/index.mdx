`sonarqube` is a terminal client for SonarQube. It answers "why is the gate red" in a few lines, lists issues and hotspots, and opens an interactive dashboard when you run it with no command. It is built on the [`@kud/sonarqube`](https://github.com/kud/sonarqube) core, so it shares its configuration with the MCP server.

## What's here

- [🚦 Quality gate](/projects/sonarqube-cli/docs/quality-gate) — read the gate, see failing conditions first, and fail a CI job on it
- [🖥️ Dashboard](/projects/sonarqube-cli/docs/dashboard) — the interactive issues view, its keys and filters
- [🧰 Commands](/projects/sonarqube-cli/docs/commands) — issues, hotspots, rules, measures and the rest, with their flags
- [⚙️ Configuration](/projects/sonarqube-cli/docs/configuration) — host, token, project and how the layers combine
