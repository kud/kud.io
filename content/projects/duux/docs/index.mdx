title: 👋 Introduction
description: A library for controlling Duux Whisper Flex 2 smart fans through the Cloudgarden cloud API and a local MQTT broker.
---

`@kud/duux` controls Duux Whisper Flex 2 smart fans — passwordless sign-in, device discovery, one-shot commands, and a stateful session that reacts to state changes over either Duux's Cloudgarden cloud API or a local MQTT broker. It's the core library behind `@kud/duux-cli`, the terminal client.

## What's here

- [🚀 Getting Started](/projects/duux/docs/getting-started) — install, sign in, and discover your fans
- [🔍 Discovery & Devices](/projects/duux/docs/discovery) — listing fans, addressing them correctly, and renaming them
- [🎛️ Commands](/projects/duux/docs/commands) — the `tune set <param> <value>` grammar and every builder
- [🔁 Sessions](/projects/duux/docs/sessions) — a live, event-driven connection to a fan
- [🔌 Transports](/projects/duux/docs/transports) — cloud vs local MQTT, and the protocol quirks of each
- [📚 API Reference](/projects/duux/docs/api-reference) — the full export surface
